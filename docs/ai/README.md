# AI context system

Store resumable facts, not chat transcripts.

- `CURRENT_STATE.md`: short current GitHub/repo checkpoint.
- `WORKFLOW.md`: Claude Builder -> ChatGPT/Codex Reviewer -> Gemini Final Verifier.
- `work/<feature>/{state.md,progress.md,implementation-plan.md}` only for genuine multi-session work.

Per-phase files are optional and should exist only when substantial independent detail is needed.
